# E-Commerce Sales Analysis
An interactive data analysis project using a sample Superstore sales dataset to extract actionable business
insights. This analysis explores sales trends across multiple dimensions, including region, product category,
and customer segment, all visualized through an interactive dashboard.
## Tools & Technologies Used
- Python - Core programming language for analysis
- Pandas - Data cleaning and manipulation
- Streamlit - Building interactive web-based dashboards
- Plotly - Dynamic and engaging visualizations
- Matplotlib & Seaborn - For static, exploratory visualizations
- Excel - Used for initial data inspection and preprocessing
# How to Run the Project
1. Clone the repository:<br>
 git clone https://github.com/Injmam08/E-Commerce-Sales-Analysis.git <br>
 cd E-Commerce-Sales-Analysis
2. Install dependencies:<br>
 pip install -r requirements.txt
3. Launch the Streamlit app:<br>
 streamlit run app.py
# Key Insights / Outcomes <br>
- Highest Sales Regions: <br> The West and East regions contribute the most to overall sales.
- Top Performing Categories: <br> Technology products yield the highest revenue and profit margins.
- Segment Analysis: <br> Consumer segment dominates in sales volume, while Corporate has better profit ratios.
- Shipping Trends: <br> Standard Class is the most used shipping mode, potentially affecting delivery time.
